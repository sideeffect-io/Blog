# Politique de confidentialité - Carnet AAC

Date de version : 8 mai 2026

Carnet AAC est une application de suivi personnel des trajets de conduite accompagnée. L'application n'est pas un service officiel et ne remplace pas le livret d'apprentissage, l'auto-école, l'ANTS ou les documents à présenter lors d'un contrôle.

## Données traitées

L'application peut enregistrer sur l'appareil les données que vous saisissez ou validez :

- trajets : date, lieu de départ, lieu d'arrivée, kilomètres, durée, mode de saisie et notes ;
- véhicules : nom du véhicule et véhicule par défaut ;
- export PDF : fichier temporaire généré uniquement lorsque vous lancez l'export.

Lorsque vous démarrez un trajet GPS, l'application utilise la position de l'iPhone pour estimer la distance. L'itinéraire complet n'est pas conservé dans le carnet. À l'arrêt du trajet, les points de départ et d'arrivée peuvent être envoyés aux services Apple de géocodage afin de proposer un nom de ville.

## iCloud et partage

Si iCloud est activé pour l'application, les données du carnet peuvent être synchronisées par Apple CloudKit dans votre compte iCloud. Si vous utilisez le partage iCloud, les comptes invités peuvent accéder aux données partagées selon les droits que vous accordez.

Cette version ne contient pas de serveur applicatif propre à Carnet AAC, pas de publicité, pas de SDK analytics et pas de suivi publicitaire tiers.

## Permissions

La localisation est demandée uniquement pour démarrer un trajet GPS. L'autorisation de localisation en arrière-plan est optionnelle et sert uniquement à continuer l'estimation d'un trajet explicitement démarré lorsque l'application n'est plus au premier plan. Le choix d'utiliser l'arrière-plan est mémorisé localement pour les prochains trajets et reste modifiable avant de démarrer un trajet. Vous pouvez retirer cette permission dans les réglages iOS.

## Conservation et suppression

Les données restent dans le carnet jusqu'à leur suppression par l'utilisateur, la suppression de l'application ou les règles applicables à son compte iCloud. L'écran "Mentions et confidentialité" permet d'effacer les trajets et véhicules du carnet actif. Si iCloud est activé, la suppression est synchronisée par iCloud.

## Contact

Les demandes relatives à la confidentialité doivent être adressées via les coordonnées du développeur affichées sur la fiche App Store. Pour une publication App Store, cette politique doit être hébergée à une URL publique et cette URL doit être renseignée dans App Store Connect.
